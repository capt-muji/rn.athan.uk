## Findings

1. **Cold start fails the <1s bar on BOTH platforms** (3.7s Android / 2.7s iOS) — Phase 3 backlog #1.
2. **Android warm/bg resume is excellent** (~85–90ms) — activity-resume path is fine.
3. **iOS warm/bg-to-content ~1.2s** vs Android ~85ms — asymmetric; part harness bias, needs
   xctrace App Launch cross-check before treating as a code finding.
