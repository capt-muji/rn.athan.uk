## Method notes (for the next wave)

- masjidbox athany walk: `api.masjidbox.com/1.0/masjidbox/landing/athany/<slug>?get=at&days=7&begin=<ISO>`
  with the held global key; 7-day hops; overlap conflicts and `isStale` must be checked
  (`tools/mb_walk.py`). No search route exists on the API — slugs come from search engines.
- mawaqit slug discovery is search-engine-only: the static site has no directory, the search
  API is key-gated (401), the HA and Python clients embed no public key, the mobile app
  source is private. Slug guesses (`mawaqit.net/en/<city>`) 404 across the board.
- masjidal (216 tenants) is US/CA/GB/AU/HK/MU/CL — useless for this capital set.
- Baab (openbaab.com) is America-only (US states + territories) — useless for sovereign
  Pacific/Caribbean small states.
- Half-hand-set mawaqit boards need the per-column rule fitter (`tools/fityear3.js`): solar
  columns, pinned clocks (>=80pc single value), free twilight angles, maghrib+interval —
  then `jointAllFive` as the gate.
