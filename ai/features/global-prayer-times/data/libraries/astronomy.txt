# decl error in ARCSECONDS, EoT error in SECONDS OF TIME. n = 365 or 366 dates per year, daily.
#
# The three test years are not a trend. The declination error of a truncated
# periodic series oscillates in SIGN with the 18.6-year nutation cycle rather
# than growing away from the epoch: sampling adhan every 2 years from 2010 to
# 2046 gives signed annual peaks of +7.50, +7.83, +8.42, -10.63, +6.69, -7.58,
# +6.39, -7.15, +11.67, -7.90, -7.17, -11.41, +8.22, +7.55, +7.35, -9.33,
# +7.05, -6.69, +6.96 arcsec, with no secular drift. 2026 is simply a high
# year, so the max below is a fair worst case and not a special case.

## Engine basis, from source
- `adhan@4.4.6`: Meeus, Astronomical Algorithms ch.25, with nutation and apparent obliquity (SolarCoordinates.ts L13-54)
- `pray-calc@2.4.0 (nrel-spa)`: NREL SPA via `nrel-spa`, claimed +/-0.0003 deg (1.08 arcsec), -2000 to 6000
- `praytime@3.2.0`: USNO "Computing Approximate Solar Coordinates" two-term series, claimed about 1 arcminute within two centuries of 2000 (praytime.js L246-260)
- `praytimes@0.0.5`: the same USNO two-term series, PrayTimes.org v2.5 (praytimes.js sunPosition)

## Where the declination error actually comes from

`adhan` and `pray-calc` return the same declination to 0.005 arcseconds
(measured: 8.24260433 versus 8.24260558 degrees on 2026-04-11), despite one
using Meeus and the other NREL SPA. So their shared ~12 arcsec peak is not a
coding difference. Tracing it one step up the chain on the same date:

| quantity | value | versus oracle |
|---|---|---|
| adhan apparent ecliptic longitude | 21.126636 deg | +31.46 arcsec |
| astronomy-engine apparent ecliptic longitude | 21.117897 deg | reference |
| resulting declination error | | +11.49 arcsec |

The error is in the SOLAR LONGITUDE, not the obliquity or the declination
formula. Both libraries carry the same truncated equation of the centre
(`solarEquationOfTheCenter`, Astronomical.ts L58-67: three sine terms), which
omits the planetary perturbation terms that VSOP87 and the JPL ephemerides
include. The projection factor from ecliptic longitude onto declination is
`cos(eps) cos(lambda) / cos(delta)`, which is about 0.37 in April, so 31.5
arcsec of longitude becomes about 11.7 arcsec of declination. This bounds the
honest accuracy claim: neither library is a 1-arcsecond ephemeris, whatever
its dependency advertises, and both are far better than they need to be for
a time quoted to the minute below 65 degrees.
